# 성정원통사의원 환자 안내 화면

성정원통사의원 환자용 주소는 보담 시작 화면의 헤더·색·글꼴과 반응형 배치를 사용합니다. ‘시작하기’를 누르면 ‘예상 부담액 확인’, ‘내 실손보험 확인 방법’, ‘진료비·청구 서류 안내’를 이용할 수 있습니다. 로그인과 환자 식별 정보 입력이 없고, 계산에 사용하는 확인 여부와 금액은 현재 화면에서만 사용합니다. 서버로 보내거나 브라우저 저장소에 남기지 않습니다.

## 예상 부담액의 근거와 범위

2026-11-23에 공개 자료를 확인했습니다.

- [병원 공식 비급여 가격표](https://www.tongsaclinic.com/sub/unpaid.php): 체외충격파 한 부위 100,000원, 프롤로 주사 한 부위 50,000~100,000원. 체외충격파는 공시 금액이 실제 치료비와 같은 경우, 프롤로 주사는 병원이 확인한 금액을 공시 범위 안에서 입력한 경우에만 계산합니다.
- [KB손해보험 실손의료비보장보험(23.01) 약관](https://kbinsure.co.kr/CG802030003.ec?fileNm=23870_1_1.pdf), 인쇄된 77쪽 및 다음 쪽: 3대 비급여 특약으로 보상되는 체외충격파치료·증식치료의 1회 공제액은 30,000원과 치료비의 30% 중 큰 금액입니다. 연 350만 원·50회 한도와 최초 10회 이후의 추가 조건이 있습니다.
- [심평원 행위 비급여 목록](https://www.hira.or.kr/ebooksc/2026/03/BZ202603053039374.pdf): 체외충격파치료(근골격계질환) SZ084, 증식치료(사지관절·척추) MY142/MY143. 의원의 실제 청구 코드는 공개 가격표만으로 확인되지 않으므로 화면에서 환자가 세부내역서 또는 원무과를 통해 확인하도록 안내합니다.

유효한 해당 계약의 3대 비급여 특약, 해당 청구 항목과 실제 치료비, 보험사의 치료 목적 보장 확인, 합산 첫 10회 이내 및 잔여 한도 70,000원 이상을 모두 확인한 경우에만 한 번의 한 부위 치료비·예상 실손보험금·보험금 수령 뒤 예상 부담액을 표시합니다. 현재 공시 금액 상한 100,000원에서 최대 계산 보험금은 70,000원입니다. 진찰료·검사료·다른 치료, SNEPI 등 다른 청구 항목, 11회차 이후, 다른 계약은 계산하지 않습니다. 이 화면은 실제 지급 여부를 판정하지 않습니다.

## 실행 및 게시

저장소 루트에서 `npm ci`, `npm run build:patient-kiosk`, `python -m http.server 3419 --bind 127.0.0.1 --directory dist-ssr/patient-kiosk`를 실행하고 `http://127.0.0.1:3419/`를 엽니다. 계산 시험: `npx vitest run tests/patient-kiosk/estimate.test.ts`.

Render: 기존 `bodam-seongjeongwon-patient-kiosk` Static Site의 게시 경로는 `dist-ssr/patient-kiosk`입니다. 배포 빌드는 별도의 관리자·운영·베타 서버, API 또는 합성 카탈로그를 참조하지 않습니다. 공개 주소에서 익명으로 시작하기 → 예상 부담액 확인 → 조건 확인 전/후 계산, 두 안내 링크와 복귀를 확인합니다.

안내 참고: [생명보험협회 가입 내역 조회](https://cont.insure.or.kr/cont_web/information/information.do), [손해보험협회 보험사 상담 안내](https://consumer.knia.or.kr/consumer/mCenter/ga2.do).
