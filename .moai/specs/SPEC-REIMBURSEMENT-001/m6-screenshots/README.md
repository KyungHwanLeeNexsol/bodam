# M6 주요 화면 사진 (2026-11-04, 최종 코드 기준 재촬영)

세로 1080×1920 · 가로 1920×1080, 설치된 Chrome, 배율 1. 이 사진은 **육안 검토용**이며 시험의 증거가 아니다(시험 통과는 `../m6-ac-trace.md`).

- **실제 핸들러 층(R)**: 파일 이름이 `real-` 로 시작한다. 시험용 앞단 서버가 실제 핸들러·엔진으로 시험 자료(`TEST_FIXTURE`)를 계산한 응답이다. 금액은 고정 응답이 아니라 계산된 값이다(병원 결제 25,000 / 보험금 24,000 / 보험금 수령 후 본인 부담 1,000).
- **가로채기 층(I)**: `real-` 이 없는 파일(보장 제외, 서류 규칙 없음, 통신 오류, 이용 완료). 실제 핸들러 세계가 이 상태를 만들 수 없어 시험이 응답을 가로채 만들었다. 시험 자료이며 실제 서버 응답이 아니다.
- 모든 사진의 병원 이름·치료 이름·금액은 시험 자료이고, 계산 결과 화면 맨 위에 "테스트 데이터로 계산한 예시입니다. 실제 보험금 안내에 사용할 수 없습니다."가 보인다.
- `-large` 는 큰 글자 보기다(결과 화면만 담았다). 나머지 큰 글자·그 밖의 화면 사진은 `SHOTS=1 npx playwright test inventory` 로 `.moai/state/shots/` 에 다시 만들 수 있다(git 이 보지 않는 곳).
- 이 중 직접 열어 본 사진의 목록은 `../progress.md` 의 "이어받기 세션"에 있다. 이 폴더의 모든 사진을 한 장씩 본 것은 아니다.

## 미리보기 사진 (2026-11-04, `npm run preview:kiosk` 를 빌드부터 실제로 띄워 브라우저로 한 번 끝까지 쓴 것)

`preview-` 로 시작하는 파일. 실제 핸들러·엔진이 시험 자료로 계산한 응답이고(금액 25,000 / 24,000 / 1,000), 맨 위 노란 띠가 앞단이 고정한 시험 데이터 안내다. 두 방향(`portrait`, `landscape`)을 모두 담았다. 사진 생성 기록은 `preview-run-log.txt`.

- `preview-*-1-start` 시작, `-2-generation` 세대 선택(경계 안내 한 줄이 없다), `-3-generation-help` "세대를 모르겠어요" 도움말(경계 안내 "가입 시기 경계 안내: 문구 검토 중" 한 줄과 확인 중 표시), `-5-result` 정상 결과(앱 안의 결과 배너와 맨 위 고정 띠가 함께 보인다), `-6-complete` 이용 완료.
- `preview-production-not-found-portrait`: 운영 구성 그대로(앞단 없이) 연 모습. 키오스크 문서는 HTTP 200, 병원 조회 API 는 404, 화면은 "이 화면은 이용할 수 없어요" 안내이고 시험 안내 띠가 없다.
- 세대 선택 화면(`-2-generation`)은 세로에서 아래 도움말 패널이 "아래에 더 있어요" 표시 뒤로 이어지는 스크롤 화면이다(고정 띠가 세로 높이를 약 70px 가져간다). 이 사진은 직접 열어 봤다. 위 `real-K01_Generation_Selected-*` 두 장은 경계 안내가 세대 선택 화면에 있던 시점의 사진이라 지웠다.
