# M6 주요 화면 사진 (2026-11-04, 최종 코드 기준 재촬영)

세로 1080×1920 · 가로 1920×1080, 설치된 Chrome, 배율 1. 이 사진은 **육안 검토용**이며 시험의 증거가 아니다(시험 통과는 `../m6-ac-trace.md`).

- **실제 핸들러 층(R)**: 파일 이름이 `real-` 로 시작한다. 시험용 앞단 서버가 실제 핸들러·엔진으로 시험 자료(`TEST_FIXTURE`)를 계산한 응답이다. 금액은 고정 응답이 아니라 계산된 값이다(병원 결제 25,000 / 보험금 24,000 / 보험금 수령 후 본인 부담 1,000).
- **가로채기 층(I)**: `real-` 이 없는 파일(보장 제외, 서류 규칙 없음, 통신 오류, 이용 완료). 실제 핸들러 세계가 이 상태를 만들 수 없어 시험이 응답을 가로채 만들었다. 시험 자료이며 실제 서버 응답이 아니다.
- 모든 사진의 병원 이름·치료 이름·금액은 시험 자료이고, 계산 결과 화면 맨 위에 "테스트 데이터로 계산한 예시입니다. 실제 보험금 안내에 사용할 수 없습니다."가 보인다.
- `-large` 는 큰 글자 보기다(결과 화면만 담았다). 나머지 큰 글자·그 밖의 화면 사진은 `SHOTS=1 npx playwright test inventory` 로 `.moai/state/shots/` 에 다시 만들 수 있다(git 이 보지 않는 곳).
- 이 중 직접 열어 본 사진의 목록은 `../progress.md` 의 "이어받기 세션"에 있다. 이 폴더의 모든 사진을 한 장씩 본 것은 아니다.
