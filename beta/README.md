# 보담 손해사정사 1인용 비공개 키오스크 베타

초대받은 검토자 한 명이 **합성 시험 데이터**로 키오스크 화면을 처음부터 끝까지(선택 → 결과 → 근거 → 서류) 확인하는 비공개 배포본입니다.
실제 환자·병원 자료는 들어 있지 않습니다. 운영 구성(`src/`)은 바뀌지 않았고(메모리 저장소의 복원 함수 두 개만 더해졌습니다), 이 폴더는 운영과 별개의 두 번째 조립 지점입니다.

## 무엇이 열려 있나

| 경로 | 초대 없이 | 초대 세션 있음 |
|---|---|---|
| `/healthz` | `ok` 한 줄(호스팅 상태 확인용, Host·종료일과 상관없이 답함) | 같음 |
| `/beta/enter`, `/beta/enter.js` | 입장 화면 | 같음 |
| `/` | 401 | 시험 시나리오 목록 |
| `/kiosk/test-fixture-clinic-1`, `…-2` | 401 | 키오스크 화면(시험 데이터 띠 + 앱) |
| `/_next/static/**` | 401 | 화면에 필요한 정적 파일 |
| `GET /api/clinics/{병원}/catalog`, `GET …/insurance/options`, `POST …/estimate` | 401 | 실제 계산 핸들러 |
| 그 밖의 모든 경로(관리자 화면·관리자 API·쓰기 API 포함) | 401 (메서드와 상관없이 같음. 화면은 HTML, `/api/`는 JSON) | 404 (지원하지 않는 메서드는 405) |

- 틀린 `Host` 헤더는 초대 여부와 상관없이 403입니다(DNS 재바인딩 방지). `/healthz`만 예외입니다.
- **접속 종료일**(`BODAM_BETA_EXPIRES_ON`)이 지나면 `/healthz` 말고 모든 요청이 410입니다(입장·화면·API·정적 파일 모두, 초대 세션이 있어도).
- 관리자 화면과 관리자 API는 **빌드에 들어 있지 않고**(`npm run beta:build`가 라우트 목록을 검사합니다) 요청 처리기에도 길이 없습니다.
- 저장소는 읽기 전용입니다(읽기 이름이 아닌 모든 메서드·내부 상태는 막힙니다). 계산 출처는 `TEST_FIXTURE` 하나만 받습니다.

## 접근 방식

1. 운영자가 초대 토큰을 만듭니다: `npm run beta:invite` (256비트, 43자). 서버 환경 변수 `BODAM_BETA_INVITE_TOKENS`에 넣습니다(쉼표로 여러 개, 최대 10개).
2. 검토자에게 초대 링크를 전합니다: `https://<공개 주소>/beta/enter#t=<토큰>` — 토큰이 `#` 뒤에 있어 서버 로그와 Referer에 남지 않고, 입장 직후 주소창에서도 지워집니다.
3. 입장하면 HttpOnly 세션 쿠키(기본 8시간, 메모리 세션)가 생기고, 그 쿠키가 있어야 화면과 계산 API가 모두 열립니다. 서버가 다시 뜨면(호스팅 재시작·무료 플랜 중지 포함) 모든 세션이 사라지므로 **초대 링크로 다시 입장**합니다.
4. 검토를 마치면 시나리오 목록의 "검토 마치고 나가기"로 세션을 끝냅니다.

## 시나리오 두 개

| | 병원 주소 | 고르는 순서 | 기대 결과 |
|---|---|---|---|
| 1. 정상 계산 | `/kiosk/test-fixture-clinic-1` | 4세대(C4) · 손해보험사 · 원인 모름 · 합성 치료 1개 → "예상 부담액 확인" | 예상 병원 결제액 15,000원 · 예상 보험금 14,000원 · 본인 부담 1,000원. "계산 근거 보기"와 "보험 청구에 필요한 서류 확인"이 열림 |
| 2. 산출 보류 | `/kiosk/test-fixture-clinic-2` | 같은 순서 | 금액 대신 "산출 보류 · 확인이 필요한 내용"이 나옴(예상 보험금 없음) |

모든 화면 맨 위에는 "테스트 데이터로 계산한 예시입니다. 실제 보험금 안내에 사용할 수 없습니다."가 고정돼 있습니다.

## Render 무료 Web Service로 배포

`render.yaml`(저장소 루트)이 서비스 하나를 정의합니다: 무료 플랜 · 싱가포르 · Node 24.22.1 · `autoDeployTrigger: "off"`(저절로 재배포하지 않음).

1. Render 대시보드에서 이 저장소(`deploy/private-kiosk-beta` 브랜치)로 Blueprint를 만듭니다. 싱가포르에서 **무료** 인스턴스가 선택되지 않으면 멈춥니다(유료로 올리지 않습니다).
2. `BODAM_BETA_INVITE_TOKENS`는 저장소에 값이 없습니다(`sync: false`). 서비스를 만들 때 대시보드에 `npm run beta:invite`로 만든 토큰을 직접 넣습니다.
3. 접속 주소는 Render 대시보드에 표시된 `https://….onrender.com` 주소입니다(서비스 이름이 이미 쓰이면 이름에 접미어가 붙으니 **주소를 직접 만들지 말고 대시보드의 것을 그대로 복사**하세요). 공개 출처는 Render가 넣는 `RENDER_EXTERNAL_URL`을 자동으로 씁니다.
4. 무료 서비스는 15분 동안 요청이 없으면 중지되고 다시 열 때 약 1분이 걸립니다. 호스팅이 언제든 재시작할 수 있으며 그때마다 세션이 사라집니다. 한 달 무료 인스턴스 시간은 750시간입니다.
5. 접속 종료일은 `render.yaml`의 `BODAM_BETA_EXPIRES_ON`입니다. 종료일 뒤에는 서비스를 중지하거나 삭제해 주세요(410만 돌려주는 상태로 남습니다).

## 로컬 실행 (요구: Node 24 이상)

```bash
npm ci
npm run beta:build        # 관리자 없는 키오스크 전용 Next 빌드(.beta-build/)
export BODAM_BETA_PUBLIC_ORIGIN=http://127.0.0.1:3401
export BODAM_BETA_INVITE_TOKENS=<npm run beta:invite 로 만든 토큰>
npm run beta:start        # PORT 또는 BODAM_BETA_PORT(기본 3401)
```

| 환경 변수 | 뜻 |
|---|---|
| `BODAM_BETA_PUBLIC_ORIGIN` | 브라우저가 보는 출처. 없으면 `RENDER_EXTERNAL_URL`. https 필수(루프백만 http 허용). 이 값의 host가 허용 Host이고, 쓰기 요청의 Origin이 이 값과 같아야 합니다 |
| `BODAM_BETA_INVITE_TOKENS` (필수) | 초대 토큰. 각 32~128자 `[A-Za-z0-9_-]`, 서로 다른 글자 12종 이상 |
| `BODAM_BETA_HOST` · `PORT`/`BODAM_BETA_PORT` | 바인딩 주소(기본 127.0.0.1)·포트(기본 3401). Render는 `PORT`를 넣고 `render.yaml`이 host를 0.0.0.0으로 정합니다 |
| `BODAM_BETA_EXPIRES_ON` | 접속 종료일 YYYY-MM-DD(한국 시간 그 날 23:59:59까지). 없으면 기한 없음 |
| `BODAM_BETA_SESSION_HOURS` | 세션 수명(1~72, 기본 8) |
| `BODAM_BETA_TODAY` | 판정 기준일(YYYY-MM-DD) 고정. 없으면 시스템 날짜(한국 시간) |

- 시작할 때 두 시나리오를 실제 핸들러로 계산해(정상 = ESTIMATED, 보류 = ON_HOLD) 다르면 **시작하지 않습니다**(종료 코드 6).
- **합성 규칙의 유효 기간은 2026-01-01 ~ 2026-12-31입니다.** 이 기간이 지나면 시작 점검이 실패합니다.
- 서버 앞단은 TLS(HTTPS)를 맡고 `Host`를 그대로 넘겨야 합니다. 프록시가 Host를 바꾸면 403입니다.

## 이 브랜치의 구성

배포에 필요한 파일만 담았습니다: `beta/`(서버·게이트·빌드·합성 스냅샷·로더·초대 토큰 생성), `render.yaml`, `src/server/repo/memory/`의 복원 함수 두 파일, `package.json`의 `beta:*` 스크립트, `tsconfig.json`의 포함 범위, `.gitignore`.
시험(`tests/beta`)·실제 브라우저 검증 도구·스냅샷 생성 도구·보고서는 개발 브랜치 `feature/pilot-private-kiosk-beta`에 있습니다. 이 저장소에는 비밀번호·초대 토큰·SQLite 파일·로컬 검증 증거를 올리지 않습니다.

## 알려진 한계

- **운영 화면과 다른 한 곳**: 키오스크 전송 코드는 쿠키를 싣지 않는 `credentials: 'omit'`이라 초대 쿠키로 계산 API를 막을 수 없습니다. 베타 빌드(`.beta-build/`)에서만 `'same-origin'`으로 바꿉니다(정확히 한 군데, 아니면 빌드 중단). 운영 `src/`는 그대로입니다.
- 세션은 메모리에만 있어 서버가 여러 대면 쓸 수 없습니다(1대 전제).
- 초대는 "토큰을 아는 사람"의 증명일 뿐 개인 인증이 아닙니다(MFA·계정 관리 없음). 실제 직원·환자 자료 앞에서는 부족합니다.
- 틀린 토큰 한도는 서버 전체 기준(10분에 30번 넘으면 틀린 토큰에 429)입니다. 맞는 토큰은 한도와 상관없이 통과하므로 익명 사용자가 검토자를 잠글 수는 없습니다. 토큰이 256비트(`npm run beta:invite`)라 추측은 현실적이지 않습니다. 설정은 글자 종류가 12종 미만인 토큰을 거절하지만 엔트로피를 보증하지는 못하니 직접 만들지 말고 `beta:invite`를 쓰세요.
- 시험 데이터 띠는 **브라우저 수준의 표시 장치**입니다. 초대받은 클라이언트가 `Sec-Fetch-Dest: iframe` 헤더를 직접 보내면 띠 없는 앱 문서를 받을 수 있습니다(보안 통제가 아님). 서버가 직접 만드는 화면(입장·차단·목록·404·종료)과 브라우저로 여는 키오스크 화면에는 항상 띠가 있습니다. Next가 만드는 오류 본문(예: 없는 정적 파일의 404)에는 띠가 없습니다.
- 초대 링크의 `#t=토큰`은 입장 직후 주소창에서 지워지지만, 브라우저 방문 기록·동기화에는 이동 시점의 주소가 남을 수 있습니다. 토큰은 개별 폐기가 없는 지참자 토큰이라, 검토가 끝나면 환경 변수의 토큰을 바꾸고 다시 시작하거나 서비스를 중지·삭제해 폐기하세요.
- 정적 파일(`/_next/static/**`)은 `Cache-Control: private`(브라우저만 캐시, 공유 캐시·CDN은 저장하지 않음) + `Vary: Cookie`로 나가고 오류 응답은 `no-store`입니다. `X-Powered-By`는 내보내지 않습니다. 앞단 캐시가 이 헤더를 무시하면 세션 없이도 캐시된 정적 파일이 나갈 수 있으니 호스팅의 캐시 동작을 확인하세요(정적 파일은 앱 코드이며 저장소가 공개라 비밀은 아닙니다).
- 로컬 http 시험에서는 쿠키가 포트를 가리지 않아 같은 호스트의 다른 로컬 서비스가 읽거나 덮어쓸 수 있습니다(공개 https에서는 `__Host-` 접두어로 막힙니다). 세션 저장소는 최대 64개이고 가득 차면 가장 오래된 것부터 밀립니다.
- 인증 없는 요청이 표준 출력 로그를 가득 채우는 것은 막지 않습니다(요청 한 줄씩 남음). 접근 기록은 시각·메서드·경로·상태·검토자 번호뿐이고 쿼리·쿠키·본문·토큰은 남기지 않습니다.
